# VR Safety Education for Beach Hazard Awareness

Unityを用いて、海辺に潜む危険を体験的に学習できるVR教材を開発しています。

## 概要

海辺には、離岸流や岩場、水中の危険生物など、事前に知識がなければ気付きにくい危険が存在します。

本プロジェクトでは、VR空間内に海辺の環境を再現し、利用者が自ら危険箇所を探しながら学習できる教材を開発しています。

日本ライフセービング協会の協力のもと、海辺の安全教育への活用を想定して制作しています。

## 開発背景

従来の紙面やWeb教材では、危険に関する知識を得ることはできますが、実際の海辺に近い状況の中で危険を探す体験には限界があります。

そこで、安全な仮想空間の中で海辺の危険を疑似体験し、自ら危険を発見するVR教材を開発しました。

## 主な機能

### 1. 海辺の危険探索

VR空間内を移動しながら、海辺に配置された危険箇所を探します。

危険箇所には選択可能なマーカーを配置し、VRコントローラーから操作できるようにしています。

### 2. 危険情報のポップアップ表示

危険箇所を選択すると、その危険について解説するポップアップを表示します。

画像と説明文を組み合わせることで、危険の特徴や安全な行動を理解できるようにしています。

### 3. 学習進捗の管理

確認済みの危険箇所を記録し、残りの探索対象を表示します。

すべての危険を確認すると、学習終了画面へ遷移します。

### 4. 行動ログの取得

利用者の移動や危険箇所の選択状況を記録します。

取得した行動ログから、利用者が見落としやすい場所や操作上の課題を分析し、教材の改善に活用しています。

## 開発上の工夫

### VR内での操作性改善

開発初期には、危険箇所によって選択しにくい場所がありました。

Colliderの範囲やオブジェクトの配置を調整し、利用者が自然に対象を選択できるよう改善しました。

### 視点・移動の調整

VR空間内を移動した際に視点の高さが変化する問題があったため、視点の高さを一定に保つよう調整しました。

移動速度についても、操作性とVR酔いの軽減を考慮して調整しています。

### UIの改善

ポップアップ内で画像と説明文が重ならないようにレイアウトを調整しました。

また、ボタンや情報表示の位置を統一し、利用者が直感的に操作できるUIを目指しています。

### 行動データを用いた改善

展示や実験で取得した利用者の行動データを分析し、危険箇所の見落としやすさを確認しています。

分析結果をもとに、危険マーカーの位置やUIへの誘導方法を改善しています。

## システム構成例

主に以下のC#スクリプトを使用して機能を管理しています。

- `GameManager.cs`
  - 学習進捗や危険箇所の確認状況を管理

- `CheckTarget.cs`
  - 危険箇所の選択・判定処理

- `PopupView.cs`
  - 危険情報の画像や説明文を表示

- `RuntimeVRGameUI.cs`
  - VR空間内のUI表示を管理

- `TitleScreenController.cs`
  - スタート画面や「つづきから」機能を管理

## 対応デバイス

- Meta Quest 3

UnityからAndroid向けにビルドし、Meta Quest 3上で動作確認を行っています。

## 今後の研究

VR教材と従来型教材を比較し、危険認知や学習効果への影響を検証する予定です。

また、利用者の行動ログを分析することで、より効果的な安全教育教材への改善を進めています。
